01 — Value

Numbers that matter.

キッズカート出展は、ファミリー層との接点設計として、他のイベント施策にない密度のエンゲージメントを生みます。1日あたりの数値はあくまで目安、会場規模によって変動します。

30-90MIN Family Engagement 1家族あたりの接触時間（体験+待機+観覧）
50-100 Rides / Day 1日あたりの体験走行人数
数千名 Booth Reach ブース来訪・観覧数（会場規模次第）
高SHARE率 SNS Spread 子供の体験写真は家族間で拡散

02 — Audience

Who you reach.

出展会場における接触対象は、ファミリー層・自動車関心層・教育関心層を中心とした、能動的に体験イベントに参加する層です。

主要参加者・同伴者

体験者
未就学児〜小学生（中心 5〜10歳）
同伴者
保護者（30〜45歳）、祖父母世代、兄弟姉妹
世帯特性
ファミリー層 / 自動車・モータースポーツ関心層 / 教育関心層

行動特性

体験単価
無料〜数千円帯の体験イベントに能動的に参加する層
SNS
体験写真は家族間でシェアされやすく、二次拡散効果が期待できる
接触時間
1家族あたり 30〜90分（体験+待機+観覧）

広告価値のポイント

  • ファミリー層との濃厚接触（1家族 30〜90分のエンゲージメント）
  • 子供の体験写真は SNS シェア率が高く、二次拡散効果が期待
  • 自動車・モータースポーツ業界との文脈整合性が高い
  • 教育・地域密着・SDGs（モータースポーツの裾野拡大）文脈での訴求も可能

05 — Sponsorship

3-tier structure.

協賛は3層構成で運営しております。今回ご案内の対象は、「出展メインスポンサー」「出展サブスポンサー」の2枠です。

既存契約

常設スポンサー

教室全体の年間スポンサー

年間契約 · 既存（TOYOPET 様）
  • 車両およびユニフォームへの通常露出
  • 子供用つなぎへのブランド掲出
  • 教室のブランドイメージ形成への寄与

※ 教室常設スポンサー様の権利は、出展メインスポンサー様の権利とは独立しております。

★ 募集中 / 1社限定

出展メイン

当該イベントにおける最大露出

出展 1回あたり · 1 社限定
  • 大型バナー × 1 掲出
  • ブース内パンフ配布
  • SNS / Web ロゴ + 紹介投稿
  • 当該イベント期間中の最大露出ポジション
独占特典
  • 車両主要部への独占的ステッカー貼付権
  • 既存ステッカーの被覆も可（期間中）
  • MC / スタッフ アナウンス
募集中 / 複数社可

出展サブ

バナー + パンフ + SNS の安定露出

  • 中型バナー × 1 掲出
  • ブース内パンフ配布
  • SNS / Web ロゴ掲載
  • 出展告知時の社名露出

06

制作物等は実費でのご請求

バナー / 横断幕 / 車両ステッカー / ノベルティ / スタッフユニフォーム ロゴ加工等の制作物は、すべて実費にてご請求申し上げます。事前にお見積をご提示いたします。

IMPORTANT NOTICE

教室 常設スポンサー様 と 出展メインスポンサー様 の権利は独立しております

福岡トヨペット様（教室常設スポンサー）の通常露出はそのまま継続します。出展メインスポンサー様には、当該イベント期間中に限り、車両主要部への独占的なステッカー貼付権をご用意いたします。
